## Latest: v0.18.22 — Mystery Box Pixels

[Download v0.18.22](https://github.com/balltro/AxiomVision-Releases/releases/tag/v0.18.22).

Mystery Box type and count now come from stable pre-open Stage pixels. The old pipeline could classify physical boxes but discarded every result when the Result-screen OCR count was unavailable. The new Bridge transaction captures up to3 fresh frames, requires2 complete agreeing observations, and records Brown/Silver/Gold/Rainbow/unknown with independent resolved count provenance. Supported calibrated layouts contain1–5 boxes, including repeated and mixed types.

A complete stable physical count is primary even when Result count is absent or conflicting. The original Result/route binding stays immutable and conflicts are recorded separately. Incomplete pixels retain a known Result total as unknown rarity; otherwise count remains unavailable. An early animated frame cannot freeze the new resolution before bounded resampling. Legacy schema1 evidence keeps its original immutable semantics.

Resolved counts survive checkpoint/recovery and feed loop records, SUMMARY and Telegram. Up to3 exact pre-open PNGs are retained with bounded whitelisted hash-bound metadata; the full diagnostic ZIP retains originals, while Telegram carries previews and reference hashes. Active Human/review evidence retains priority. Item/treasure reading remains disabled.

Open All still uses its separate exact scene/button guard. After telemetry checkpoint/PNG writes, a new action frame prevents slow diagnostic IO from aging the input witness. Stop/Pause/Human, Controller batch, Stage/geometry/watchdog and never-replay guards remain. No new coordinate authority is exposed.

## v0.18.0 (initial release)

1. Download the ZIP from the [v0.18.0 release](https://github.com/balltro/AxiomVision-Releases/releases/tag/v0.18.0).
2. Close the Controller and game workers. Back up the existing installation, extract the ZIP over the same folder without deleting runtime state, and run `RUN-SETUP-WINDOWS.bat` once.
3. Download `ENABLE-AXIOM-AUTO-UPDATE-WINDOWS.bat` from this repository. Place it beside `RUN-SETUP-WINDOWS.bat` and run it once to configure the signed feed.

The updater installs only when both Universal and Heart are idle and no active checkpoint remains. A failed package swap restores backed-up code files. The signing private key is not stored in this repository or a release asset; the archive and every included file must match the signed hashes in `updates.json`.
