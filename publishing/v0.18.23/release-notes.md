# v0.18.23 — Mystery Box Surfaces

แก้การตรวจ Mystery Box ที่ภาพเกมจริงมีแสงรัศมีด้านหลังแล้วถูกปฏิเสธผลทั้งหมด โดยตรวจขอบและตัวกล่องแยกจากพื้นหลัง และปรับตำแหน่งอ่านสีจากภาพที่จับได้เต็มความละเอียด กล่อง Brown จึงไม่หลุดเพราะการย่อภาพก่อน scan

- ใช้การตรวจภาพภายในเครื่องใน Stage ก่อน Open All ยืนยันชนิดและจำนวนจากภาพที่ตรงกันสองภาพ
- รองรับข้อมูล checkpoint เดิม v2 และ schema1 โดยไม่เขียนยอดย้อนหลังหรือส่ง input ซ้ำ
- ผลที่ตรวจใหม่ยังผ่าน checkpoint → loop statistics → Summary และ Telegram ด้วยแหล่งที่มาของจำนวนเดิม
- SEND LOG เพิ่มต้นฉบับ PNG ล่าสุดที่ตรวจกล่องภายในขนาดจำกัด พร้อมระบุเมื่อมีเพียงภาพ preview

ทดสอบภาพ Silver และ Brown ที่แนบมากับ Log v0.18.22 เป็นภาพ JPEG preview จริง ภาพเหล่านี้ใช้ทดสอบแกนประมวลผลภาพและเส้นข้อมูล ไม่ใช่ต้นฉบับ PNG หรือการทดสอบกดเกมบนเครื่องผู้ใช้ การทดสอบจำนวน 1–5 และสีอีกสองชนิดใช้ fixture ที่ระบุที่มา

หยุดงานแล้วกด CHECK UPDATE จากนั้นเริ่มรอบใหม่ ผลเก่าที่นับไม่ได้ยังคงเป็นข้อมูลเดิมเพื่อรักษาประวัติ ไม่แก้ยอดย้อนหลังจากภาพ preview
