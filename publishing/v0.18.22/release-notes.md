# Axiom Vision v0.18.22 — Mystery Box Pixels

ตรวจชนิดและจำนวน Mystery Box จากพิกเซลใน Stage ก่อนเปิดกล่อง
แก้จุดเดิมที่ตรวจกล่องได้แต่ทิ้งผลทั้งหมดเมื่อ OCR หน้า Result อ่านจำนวนไม่ได้

- ตรวจ Brown / Silver / Gold / Rainbow และจำนวนแยกชนิดจากภาพก่อน Open All
  ใช้ calibration และ layout ที่ตรวจสอบไว้สำหรับ 1–5 กล่อง รวมกล่องชนิดเดียวกันหลายใบ
- ยืนยันภาพสดที่ตรงกัน 2 ภาพ จากการจับภาพสูงสุด 3 ครั้งก่อนบันทึก
  ภาพแรกที่กำลัง animate หรือยังอ่านไม่ครบจะไม่ตรึงผลเป็น unknown ทันที
- จำนวนจากกล่องจริงที่ตรวจได้ครบและเสถียรเป็นหลัก แม้ Result count หายหรือขัดกัน
  เก็บ Result เดิมและสถานะ conflict แยกไว้เพื่อตรวจย้อนหลัง
- ส่งผลผ่าน checkpoint / recovery / record loop ถึง SUMMARY และ Telegram
  จำนวนที่เห็นชัดแต่ชนิดไม่ชัดยังแยก unknown ออกจากจำนวนที่อ่านไม่ได้
- เก็บ PNG ก่อนเปิดล่าสุด 3 ภาพ พร้อม metadata ผูก hash และเหตุผลเมื่ออ่านไม่ครบ
  Full ZIP มีภาพจริง; Send Log มี preview พร้อมข้อมูลอ้างอิงสำหรับตรวจผล
- หลังบันทึกและเขียนภาพ จับภาพสดอีกชุดสำหรับกด Open All เพื่อไม่ใช้ภาพเก่าจากช่วงทำ IO
  ตรวจฉาก Open All/Confirm และกฎห้ามกดซ้ำตามเดิม

การจำแนกชนิดและจำนวนไม่ใช้ตัวเลข/ชื่อชนิดจาก OCR หน้า Result
ส่วนการยืนยันฉากและปุ่ม Open All สำหรับ input ยังใช้ guard เดิมแยกจากตัวอ่านกล่อง
Stop/Pause/Human, Controller batch, Stage, geometry และ watchdog ยังบล็อกได้ตามเดิม
หลักฐานเก่า schema1 ใช้กฎเดิมแบบ immutable และไม่เติมข้อมูลย้อนหลังจากการเดา
ไม่ได้เปิดระบบอ่านวัตถุดิบหรือสมบัติหลังเปิดกล่องกลับมา

การประมวลผลภาพ profile ที่ใช้ทดสอบลด median จากประมาณ 1,293 → 202 ms
เป็นเวลาวิเคราะห์ภาพบนเครื่องทดสอบ ไม่รวมจับหน้าจอ/OCR/กดบน LDPlayer
ทดสอบ Windows Python 3.12.10 ก่อนเผยแพร่ ครอบคลุมตัวตรวจพิกเซลจริงและเส้นข้อมูลถึงสรุป

ข้อจำกัดของหลักฐาน: Log ชุดวันที่ 30 ตุลาคมไม่มีภาพต้นฉบับก่อนเปิดกล่อง
การทดสอบภาพบวกใช้ HSV profiles ที่วัดไว้เดิมและภาพจำลองจาก profiles นั้น
ยังไม่ได้ยืนยัน artwork หน้ากล่องล่าสุดหรือการรับ input บน LDPlayer ของผู้ใช้
หาก layout/สีไม่เข้าชุดหรือภาพกำกวม ระบบเก็บว่าอ่านไม่ได้ พร้อมภาพอ้างอิง ไม่แต่งจำนวนขึ้นมา

อัปเดตผ่าน Settings → CHECK UPDATE เมื่อ worker หยุดและการติดตั้งพร้อม
ฟังก์ชันระบุกล่องทำงานอัตโนมัติใน Stage ก่อน Open All ไม่ต้องเปิดโหมดเพิ่ม
ดูผลชนิดและจำนวนใน SUMMARY และสรุป Telegram ของรอบหลังอัปเดต
